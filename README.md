# VideoLab

An interactive video player webpage that plays and pauses a video when hovering with the mouse.

## Features

- Embedded `<video>` element with controls
- Video plays automatically when hovered with mouse (`onmouseover`)
- Video pauses when mouse leaves (`onmouseout`)

## Technologies Used

- HTML5
- CSS3
- JavaScript 

## JavaScript Functions

| Function | Description |
|----------|-------------|
| `playVideo(video)` | Calls `.play()` on the video element |
| `pauseVideo(video)` | Calls `.pause()` on the video element |

## How to Run

1. Download all files (`index.html`, `style.css`, `script.js`)
2. Make sure the video file is inside the `assets/` folder
3. Open `index.html` in a web browser
